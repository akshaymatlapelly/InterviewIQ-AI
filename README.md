# InterviewIQ AI

This repository is structured into **`frontend`** and **`backend`** directories.

## Project Structure

```
.
├── frontend/             # React + Vite frontend application
│   ├── src/              # React components, pages, utils, api
│   ├── public/           # Static assets
│   ├── index.html
│   ├── package.json      # Dependencies and scripts
│   └── vite.config.js    # Vite configuration
│
└── backend/              # Database schemas & entity definitions
    └── iqdb/             # DB entity schemas
```

## Running the Application

### Frontend
```bash
cd frontend
npm install
npm run dev
```
